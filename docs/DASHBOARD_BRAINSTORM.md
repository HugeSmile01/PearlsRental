# Dashboard Brainstorm (User + Admin)

## User Dashboard Concepts
- **Reservation timeline**: upcoming pickup, return due date, and cancellation windows in one strip.
- **Money snapshot**: total spent, pending payments, and saved wishlist value.
- **Smart nudges**: reminders for expiring reservations and pickup location quick access.
- **Personalization**: recommendations based on category and size preference.
- **Self-service actions**: cancel, extend rental request, contact support from cards.

## Admin Dashboard Concepts
- **Operations command center**: overdue, unpaid, and today pickup counts above the fold.
- **Revenue intelligence**: paid revenue trend, AOV, and category contribution.
- **Inventory health**: status mix and low-stock/low-rotation items.
- **Customer risk view**: repeat cancellations and late return behavior.
- **Workflow accelerators**: one-click status updates and quick product CRUD.

## Implemented in this iteration
1. Added **user quick insight cards** for next pickup date, unpaid reservation exposure, and dashboard quick actions.
2. Added **admin operations cards** for overdue rentals, pending pickups, and inventory count.
3. Preserved existing tabs and workflows while surfacing actionable metrics above lists.
